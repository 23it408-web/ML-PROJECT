     requirements.txt
     README.md

HOW TO RUN THE PROJECT (Windows / Mac / Linux)
1. Install Python 3 (python.org)
2. Open a terminal inside the project_code folder
3. Run:  pip install -r requirements.txt
4. Run:  streamlit run app.py
5. The app opens in your browser at http://localhost:8501
